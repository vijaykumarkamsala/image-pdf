# Product Decision Register — V2

All items below are approved unless marked Open.

## Product and scope

- D2-001 Independent product/brand; optional later YearShift umbrella access only through stable integration.
- D2-002 Working category: Intelligent Visual Production Workspace.
- D2-003 Major outcomes appear equally; product is not framed as only scan cleanup.
- D2-004 Before external testing, include image/graphic, create PDF, edit/manage PDF, production, projects, collaboration, cloud connectors and API.
- D2-005 Exclude video editing.
- D2-006 No live charging before tester release; use zero-charge shadow pricing.
- D2-007 Same workspace model for individuals, companies and informal teams.

## Home and workspace

- D2-008 Guest upload is primary; cloud import/blank are secondary.
- D2-009 Signed-in home prioritises recent projects and quick create/import.
- D2-010 Print & Production is an equal outcome and contextual preflight inside editors.
- D2-011 Every account has a personal workspace and default project/files area.
- D2-012 Support lightweight and structured project styles.
- D2-013 Support collections and true subprojects.

## Intake and enhancement

- D2-014 Analyse safely before changing content.
- D2-015 Generate correction preview automatically; apply only after confirmation.
- D2-016 Infer intended use; ask only when materially necessary.
- D2-017 Strip sensitive metadata from exports by default; allow preserve.
- D2-018 Automatically choose safest Preserve/Restore/Recreate mode.
- D2-019 Recreate always requires explicit permission.
- D2-020 Highlight reconstructed regions and require production-export approval.
- D2-021 Show largest trustworthy size before separately offering Recreate.
- D2-022 Mixed content receives region-specific processing with protected text/faces/logos/outlines.
- D2-023 Simple result controls first; complete technical controls under Advanced.
- D2-024 Recreate produces two or three critical-region candidates before full render.

## Editor and versions

- D2-025 Normal corrections are non-destructive adjustments/masks.
- D2-026 AI results are named variants/layers.
- D2-027 Support multiple artboards with shared assets/styles.
- D2-028 Continuous autosave, persistent undo/redo, automatic and named versions.
- D2-029 Linked or independent cross-artboard objects; brand assets linked by default.
- D2-030 Smart Resize creates a new artboard and preserves the original.
- D2-031 Raster/vector/text/shapes coexist as editable layers.
- D2-032 Import verified external structures with compatibility report; native format is authoritative.
- D2-033 Task-based workspace plus All Tools/search.
- D2-034 Desktop default uses docked panels that can detach/float/pin/resize.
- D2-035 AI assistant is dockable conversation plus contextual selection actions.
- D2-036 Phone supports essential quick actions/view/comment/export; tablet near-full; desktop full.

## Production and export

- D2-037 Baseline and editable factory production profiles.
- D2-038 Critical preflight failure withholds Production-ready; authorised override requires reason unless strict.
- D2-039 Physical sample tracking is optional and profile/project controlled.
- D2-040 Digital and physical outputs have equal importance.
- D2-041 One Export Center; Download transfers an already rendered result.
- D2-042 Multi-profile/size/format export in one job; individual or ZIP delivery.
- D2-043 Versioned built-in digital presets plus custom workspace presets.
- D2-044 Render every derivative from editable master.

## Batch

- D2-045 Group compatible files automatically with visible exceptions.
- D2-046 Representative review; individual confirmation only for flags/Recreate.
- D2-047 Durable background jobs preserve successes and support checkpoint retry/cancellation.

## Create PDF and OCR

- D2-048 Quick and advanced paths use the same editor with progressive disclosure.
- D2-049 Created PDF elements remain editable in native project.
- D2-050 Uniform page size default; mixed sizes and safe normalisation allowed.
- D2-051 Cleanup/OCR proposals require confirmation.
- D2-052 Preserve visual page and separate searchable OCR; reconstruction only on request.
- D2-053 Generate accessibility structure and preflight by default.
- D2-054 Section-aware master pages with page override/detach.
- D2-055 Forms/links/bookmarks/signature fields are editable validated objects.
- D2-056 Multiple PDF output profiles from one master.

## Edit/manage PDF

- D2-057 Never silently flatten unsupported PDF content.
- D2-058 Missing/restricted fonts use licence-aware resolver and approved substitution.
- D2-059 Protect signed original; edits create labelled unsigned derivative.
- D2-060 Focused shortcuts open the shared PDF workspace.
- D2-061 Preserve unaffected native objects and disclose changes.
- D2-062 Redaction is marked/reviewed then applied to verified sanitised derivative.
- D2-063 Compression uses purpose presets, Advanced controls and comparison.
- D2-064 Repair produces recovery report.
- D2-065 Reconstructed conversion produces fidelity report.
- D2-066 Active content opens disabled in sandboxed safe mode.
- D2-067 Unlock requires valid credentials and creates derivative.

## E-sign

- D2-068 Own native e-sign UI/API/workflow; external signature vendors optional.
- D2-069 Regulated trust providers remain pluggable where law requires.
- D2-070 Recipient account is optional; secure link plus policy authentication.
- D2-071 Recommend authentication level by risk/jurisdiction; sender/workspace may enforce.
- D2-072 Support sequential/parallel/mixed and approver/signer/witness/copy roles.

## Cloud, sharing and collaboration

- D2-073 Personal and workspace-managed cloud connections with least privilege.
- D2-074 Save to cloud creates new provider file/version by default; replacement confirmed.
- D2-075 Disconnect/delete never removes external files automatically.
- D2-076 External source update creates a source version and asks; remembered rule respects frozen versions.
- D2-077 Permission inheritance with visible child overrides/origin.
- D2-078 One editor lease per document; other project documents remain editable.
- D2-079 Expired/disconnected lock autosaves/releases; takeover warned/audited.
- D2-080 Comments are version/region anchored; unresolved threads carry traceably.
- D2-081 Approval is optional per workspace/project.

## Pricing, retention, privacy and quality

- D2-082 “Free during testing”; experimental prices admin-only.
- D2-083 Transparent fair-use/safety limits; admin increases.
- D2-084 Testers see non-monetary usage.
- D2-085 Six-month deletion applies to entirely inactive free workspace with warnings/overrides.
- D2-086 Approved/signing records use explicit retention/legal holds.
- D2-087 Delete revokes immediately, trash then purge/backup expiry.
- D2-088 No model training by default; separate revocable consent and rights required.
- D2-089 Support access is approved, time-bound and audited; controlled break-glass.
- D2-090 Workspace home region with disclosed exceptions and migration.
- D2-091 Friendly diagnostics plus optional Advanced trace.
- D2-092 Elevated diagnostics scoped/expiring/reasoned/audited.
- D2-093 Retry from safe checkpoint; preserve successes; sanitised support package.
- D2-094 Release blocks known Critical/High, journey blockers and unowned Medium defects.
- D2-095 Rollout: internal QA, trusted/domain users, closed beta with flags/rollback.
- D2-096 Bug reports auto-attach safe trace; screenshots/files require review/consent.
