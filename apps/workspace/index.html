Applied

    Print size

    Tell it the size you need. It will say honestly whether this image can reach it.

    Make a PDF

    Convert to vector

    Turns a picture into shapes instead of pixels, so it stays perfectly sharp at any size — a business card or a billboard. This is what a vinyl cutter, laser, engraver or embroidery machine needs: they follow paths and cannot read pixels at all.

    Combine documents

    Add more PDFs and join them end to end. Pages are copied, not re-rendered, so nothing loses quality.

    Stamp text over the pages

    Added as its own layer. The artwork underneath is never rewritten, so a stamp cannot damage it.

    Make a scan searchable

    A scan is a picture of words: nothing can search it, copy from it, or redact a name in it. This reads the words and lays them invisibly over the page, which looks exactly the same and can then be searched — and redacted by typing a name instead of drawing a box on every page.

    Checking whether recognition is available…

    Make it smaller

    For a portal, a filing system or an email that will not take it. Give the limit and it finds the best quality that fits, or tells you plainly that it could not.

    Remove sensitive text

    This deletes the words. Most tools draw a black box and leave the text underneath, where it can still be selected, copied and found by search. Every removal here is checked by reading the finished file back.

    File size

    Design programs hide a second, editable copy of the artwork inside the file. Leaving it out often makes the file far smaller and what prints is identical - but you lose the ability to reopen it in Illustrator with live objects. Tick this if that matters.

    How pages are shown

    Each card shows a page's real measured size. There is no picture of the page because drawing one means guessing at fonts and colour, and a preview that differs from the print is worse than none. Pages holding one full-page scan show that scan.
