# Committed fixtures

Every file in `images/` is generated by a script in `tools/`, from a pure function
of its inputs. That makes them byte-reproducible on any platform and trivially
rights-clear: no third party, no people, no sensitive content.

`FIXTURES.sha256` locks their bytes. `bench fixtures verify` checks the lock, and
a session-scoped pytest guard hashes them at the start **and** end of every test
run — the mechanical proof that nothing mutates an original (D-006).

## What each fixture is for

| File | Generator | Purpose |
| --- | --- | --- |
| `synthetic-gradient-64.png` | `make_fixtures.py` | The baseline valid asset: 64×64 RGB, gradient plus checkerboard. Smooth tone for banding tests, sharp edges for sharpening and tiling tests. |
| `synthetic-grey-16.jpg` | `make_inspection_fixtures.py` | A valid 16×16 baseline JPEG. Exercises signature detection and `SOF` parsing. |
| `synthetic-grey-16x8-orientation6.jpg` | `make_inspection_fixtures.py` | 16×8 with EXIF orientation 6. Deliberately non-square so the display axes visibly swap to 8×16. |
| `mismatched-extension.png` | `make_inspection_fixtures.py` | JPEG bytes wearing a `.png` extension — the renamed-upload attack. Must be rejected. |
| `decompression-bomb.png` | `make_inspection_fixtures.py` | `IHDR` declares 60000×60000 (3.6 gigapixels) in 84 bytes. A header-first inspector refuses it; one that decodes first would try to allocate about 10 GB. |
| `unsupported-depth-16bit.png` | `make_inspection_fixtures.py` | 16 bits per channel — outside the validated depth set, so inspection warns rather than refusing. |
| `not-an-image.png` | `make_inspection_fixtures.py` | Plain text with an image extension. No recognisable signature. |
| `truncated-header.png` | `make_inspection_fixtures.py` | A PNG cut off mid-`IHDR`. Malformed, not oversized. |

## Regenerating

```powershell
python tools/make_fixtures.py --check              # verify reproducibility
python tools/make_inspection_fixtures.py --check
bench fixtures verify                              # verify against the lock
```

Both generators run in `tools/check.py`, so a fixture that stops being
reproducible fails the build.

## Why they are hand-built

POC-003 inspects headers without decoding pixels, so it needs **no imaging
library**. Generating the fixtures with one would have reintroduced exactly the
dependency the design avoids, and would have made the bytes depend on that
library's version. The PNGs use DEFLATE *stored* blocks (byte layout fixed by RFC
1951, so no zlib-version drift) and the JPEGs use the standard Annex K Huffman
tables with a hand-packed entropy segment.

**Honest limitation.** The JPEGs are structurally valid and verified against this
repository's own parser, but they have **not** been round-tripped through a
third-party decoder — POC-003 has no imaging dependency to do so with. POC-004
will confirm they decode once an imaging library enters the licence register.

## Adding a fixture

Small, synthetic and rights-cleared only. Large or private benchmark assets are
referenced from a manifest by id and hash and live in protected storage — they
are never committed (`AGENTS.md`). A test fails if any tracked file exceeds
256 KB.
